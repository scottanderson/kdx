# Find a build from between 0.921 and 1.110

Status: ready-for-human

The 0.9x handshake (Client and Server 0.915–0.921) and the 1.x one (Client
1.110 and Server 1.300 on) have no build between them in
`vendor/MANIFEST.md`, so where the handshake changed is unknown. Haxial's
2002 listings name Client and Server 0.933–0.942, but Wayback has none of
them. Applefritter has KDX Client and Server 1.0 as `.hqx` files from
info-mac (https://www.applefritter.com/node/15285). Done when one of these,
or another build from the gap, is in the manifest with its source and
checksum, or the search is recorded as fruitless.

## Comments

Ready for a human because `vendor/fetch` reads only Wayback captures of
haxial.com. A build from another site needs the maintainer to approve that
source and decide how the manifest records it.
