# Onboarding

Goal: someone with a fresh Linux machine can fetch the Haxial binaries, run
the checks, use the lab, and run static analysis from the repo docs alone.

Done so far: `vendor/fetch`, `CONTRIBUTING.md`, the README's getting-started
section, lab install steps, the Ghidra prerequisites, tests that read the
cached table, and a check that Rust 1.96 builds the workspace. The issues below
cover what could not be done or verified on the maintainer's WSL2 machine.
