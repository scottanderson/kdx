# Run the checks in CI

Status: needs-triage

There is no CI. Once the GitHub repo is pushed, add a workflow that runs
`cargo fmt --all --check`, `cargo clippy --workspace --all-targets -- -D
warnings`, `cargo test --workspace`, and the kdx-dissect run on
`captures/first-connect.pcapng`. CI has no Haxial files, so the tests that
need the table will skip. Never fetch the table or the binaries in CI.
