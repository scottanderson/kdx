# Browse a tracker from the CLI

Status: ready-for-agent
Blocked by: 02

Add `kdx tracker groups <addr>` (700/701) and `kdx tracker servers <addr>
<group>` (702/703) to `kdx-cli`, logging in as guest by default and
defaulting to port 10800. Optionally `kdx tracker stats` (720/721) with an
admin login. Try it against Tracker 1.110 in the lab and record the run in
`captures/kdx-cli.md` or a new capture.
